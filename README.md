## Quasar Engine

**[QuasarEngine](https://github.com/ultirisstudio/QuasarEngine)** is our main project — a
real-time game engine written from scratch in C++.

It exists because building an engine is one of the hardest, most rewarding things you can
take on as a developer. Rendering, memory, asset pipelines, tooling: every layer has to be
understood before it can be written. That is the point.

The engine is in active development and evolving quickly.

```
Language   C++ / CMake
Status     In active development
Repo       github.com/ultirisstudio/QuasarEngine
```
